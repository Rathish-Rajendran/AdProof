# Demo script

Start by saying this is a bounded evidence preflight—not legal advice, a legal review, platform certification, ad approval, or a safety guarantee. The assets and product are synthetic.

1. Run `demo aerobeat` in the connected ACP chat: case 1 has unsafe “completely waterproof,” 48-hour battery, athlete endorsement, and 50%-off copy with a neutral image. Compare it with the supplied page: splash-resistant/not waterproof, up to 30 hours with ANC off, no endorsement evidence, and $80 to $60 (25% off).
2. Explain each finding with its exact evidence excerpt and show the single copy-only repair proposal. State that the image remains unchanged and the revised candidate is independently re-audited; if model access fails, show the typed failure/review result rather than a fixture verdict.
3. Run `demo aerobeat49`: the same unsafe copy is paired with the original image visibly saying “Only $49.” Explain why copy repair cannot remove an image-origin issue.
4. Optionally show `demo aerobeat correct` (case 4) as audit-only with no requested repair.
5. Describe only outcomes measured in `docs/validation-status.md`. A local mock, local agent health, mailbox boot, or configured Sentry DSN does not prove model accuracy, Agentverse discovery, Sentry ingestion, or always-on service.

The supported named scope is US/English adult-targeted general consumer electronics in the reviewed Google Ads checks. Close by naming unsupported contexts and the need for human review.
