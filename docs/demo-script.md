1. State that AdProof checks a bounded set of objective claims against supplied sources; it is not legal/platform certification.
2. Show the synthetic AeroBeat facts: $80 to $60 is 25% off; battery life is up to 30 hours with noise cancellation off; splash resistance is not waterproof; no athlete endorsement evidence is supplied.
3. Compare the unsafe copy and neutral image, then present a copy-only proposed repair and independent re-audit.
4. Show that an unchanged image saying “Only $49” remains unresolved.
5. Report only measured test/live results and disclose pending registration, hosting, and Sentry evidence.
