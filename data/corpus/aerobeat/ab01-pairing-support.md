# AeroBeat AB-01 Bluetooth pairing support

This is a synthetic demonstration document; AeroBeat and all product information here are fictional.

## First-time pairing

Charge the AB-01 before setup. Turn on the headphones and place them near the phone, tablet, or computer. Open the source device's Bluetooth settings and select AeroBeat AB-01 from the available-device list. Follow any on-screen confirmation from the source device.

The AB-01 uses Bluetooth 5.3. The name shown in a device list may differ if a previous pairing has been saved or renamed. If a second device is already connected, disconnect it while setting up a new source.

## Reconnecting

If the headphones do not reconnect automatically, check that Bluetooth is enabled on the source device and that the AB-01 is powered on. Select the headphones in the saved-device list. If the connection remains unavailable, remove the old pairing from the source device and start the pairing process again.

For a fresh check, turn Bluetooth off and back on, then keep the source device close to the headphones. Restarting the source can clear a temporary Bluetooth state. Try another source device if one is available to narrow down where the issue occurs.

## Call and media audio

The source device may provide separate settings for media and call audio. Check that the intended output is selected in the app and system settings. If media plays but calls do not, review the call-audio setting and the active call application.

## Getting more help

Record the source-device type, its operating-system version if known, and whether the AB-01 appears in the Bluetooth list. Contact support with those details and the steps already attempted. Do not include private account passwords or payment details.
